ZDDC Classifier

Spreadsheet-based file renaming for ZDDC compliance

⚠️ Browser Not Supported

This application requires the File System Access API, which is only available in Chromium-based browsers.

Please use one of the following browsers:

  • Google Chrome (version 86+)
  • Microsoft Edge (version 86+)
  • Opera (version 72+)
  • Brave (version 1.15+)

or drag and drop a folder here

Features:

  • 📊 Excel-like Spreadsheet - Direct cell editing with formulas
  • 📁 Multi-Folder Selection - Work on multiple folders at once
  • 🔄 RC References - Reference other cells like Excel
  • 🔍 Regex Support - Extract patterns with capture groups
  • ✅ Auto-Validation - ZDDC compliance checking
  • 💾 Batch Operations - Save all or individual files

This application works entirely in your browser. No data is transmitted to any server.
