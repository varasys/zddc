Pain Point

Your folder structure is someone else's best guess

Someone created the folders. Nobody else agrees with their logic.

Files end up in three different places because three people had different intuitions.

You spend 10 minutes finding a file you know exists. You give up and email someone to ask where it is.

Pain Point

Which version is current?

There's Drawing_v2_final.pdf, Drawing_v2_final_REVISED.pdf, and Drawing_v2_final_REVISED_2.pdf.

The email thread says "use the latest" but nobody defined what that means.

Six months later, someone built to the wrong version. The project is delayed.

Pain Point

Prove what was current on that date

A contract dispute. A warranty claim. An audit.

"Which version of the specification was issued when the order was placed?"

You can't answer that. The emails are gone. The versions aren't dated. Nobody kept a record.

Encode the metadata in the filename. One flat folder. Your file browser becomes the search engine.

123456-EL-SPC-2623 _ B (IFC) - Specification For Switchgear.pdf
Tracking Number

Permanent ID. Never changes.

Revision

B = second formal issue

Status

IFC = Issued For Construction

Title

Human-readable description

Solution 1 — Find anything. Instantly.

Your file browser already knows how to search and sort filenames. Your search box is already there. Your filter is already there.

  • Search EL-SPC → all electrical specifications
  • Search IFR → everything under review
  • Search ~ → all working drafts
123456-EL-SPC-2623_A (IFR) - Specification For Switchgear.pdf 123456-EL-SPC-2623_B (IFC) - Specification For Switchgear.pdf 123456-EL-SPC-2624_A (IFR) - Switchgear Bill of Materials.pdf 123456-EL-SPC-2624_B (IFC) - Switchgear Bill of Materials.pdf

Solution 2 — Always know which version is current

Revision progression follows a clear pattern:

  • Letters (A, B, C...) for design/review phase
  • Numbers (0, 1, 2...) for construction/record phase
  • ~B means "working draft of revision B — not yet issued"

Sort by name and the full history is right there, in order.

123456-EL-SPC-2623_A (IFR) - Specification For Switchgear.pdf 123456-EL-SPC-2623_B (IFR) - Specification For Switchgear.pdf 123456-EL-SPC-2623_~C - Specification For Switchgear.pdf (working draft) 123456-EL-SPC-2623_0 (IFC) - Specification For Switchgear.pdf 123456-EL-SPC-2623_1 (IFC) - Specification For Switchgear.pdf 123456-EL-SPC-2623_2 (IFC) - Specification For Switchgear.pdf

Solution 3 — Prove what was current, forever

Transmittal folders use date-prefixed naming so they sort chronologically. SHA-256 checksums provide mathematical proof of file integrity.

Your receiver's archive becomes permanent, can be made read-only, and is shared with the whole team.

2025-10-31_123456-EL-SPC-2623 (IFR) - Design for Review/ 2025-11-12_123456-ME-RFI-0024 (IFR) - Mechanical Room Size RFI/ 2025-12-03_123456-EL-SPC-2623 (IFC) - Issued For Construction/

Four tools. Each a single HTML file.

Download once. Works forever. No internet, no updates, no subscription.

Archive Browser
Your digital filing cabinet. Browse, search, filter, and download. Group by transmittal. Works with any folder.
Open Archive Browser
Transmittal Creator
Fill in metadata, drag in files, publish a self-contained transmittal record with SHA-256 checksums. The published file IS the record.
Create Transmittal
Document Classifier
Spreadsheet-style bulk renamer. Copy/paste from Excel. Point it at a folder of badly-named files and fix them all at once.
Run Classifier
Markdown Editor
Browser-based markdown editor with live preview, YAML front matter, and table of contents. Works directly with local files.
Open Editor

All tools require Chrome or Edge (File System Access API). Right-click any link to save a local copy.
